A QUICK GUIDE

Binary Search Tree methods

search(self, root, key)

Compares the key with the current node. It searches the left subtree when the key is smaller, and the right subtree when it is larger. It returns the matching node or None.

post_traversal(self, start, traversal)

Visits the left subtree, then the right subtree, and finally the current node. This is the postorder sequence: Left → Right → Root.

delete_node(self, root, key)

Finds the node and removes it. It handles a node with no child, one child, or two children. For two children, it replaces the node with its inorder successor.

Example

Insert 50, 30, 70, 20, 40, 60, 80. The postorder traversal is 20, 40, 30, 60, 80, 70, 50.
